Mock publisher article

This page simulates what a small-publisher website looks like after they paste in the PopularNetworkWidget.init(...) snippet. The chat bubble in the bottom-right is loaded by /static/widget.js, configured for businessId: 1 (Quadd.ai).

Click the bubble, type a question, and you should get a Claude-generated reply that uses Quadd's voice brief as system context. The session id persists to sessionStorage so a page refresh continues the same conversation.

Requires: ANTHROPIC_API_KEY env var set when running the server (uv run python -m app.main). Without it the widget shows a "temporarily unavailable" message.

Try sending:

  • "What does Quadd.ai do?"
  • "Tell me about pricing"
  • "Can I talk to a human?" (should set escalation_flag = true in the dashboard)

Sessions land in Settings → Chatbot Preview on the dashboard with source='ingested'.
