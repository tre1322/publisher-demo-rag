# Dashboard Build Brief — Popular Network Marketing Agent

**Read this file first, then read `business-plan.md` and `execution-plan.md` in this same folder before starting.**

## What you're building

A polished sample dashboard demonstrating what a Tier 2 / Tier 3 business owner sees when they log into the Popular Network Marketing Agent. This will be shown to a strategic partner to communicate the product vision. It is a static demo with mock data — no backend, no real APIs.

## Build constraints

- **Single self-contained HTML file** with React + Tailwind via CDN. No build step, no npm install. The user should be able to double-click `dashboard.html` and have it open in their browser.
- React 18, Tailwind CSS via CDN, lucide-react for icons (also CDN).
- All data is mock data, hardcoded as JS objects in the file.
- Place the final file at the root of the project folder (one level up from `docs/`) so it's easy to find.

## The fictional business for the demo

Use this business throughout so the dashboard feels real:

- **Name:** Westbrook Auto & Tire
- **Type:** Local auto repair and tire shop
- **Location:** Westbrook, Minnesota
- **Owner:** Dale Henderson, owner-operator with one technician
- **Tier:** Tier 2 ($299/month)
- **Joined:** 47 days ago
- **Voice interview completed:** yes
- **Recommended ad spend:** $200/month, currently spending $150/month on Meta and Google combined

Populate every section with realistic, locally appropriate content for this business. Use small-town Minnesota voice — friendly, direct, no corporate fluff. Posts should be about oil changes, winter tire swaps, brake jobs, the local high school football team, that sort of thing.

## Required views

The dashboard should have a left sidebar navigation with these sections, each fully populated with realistic mock content:

### 1. Home / Overview
- Welcome header with owner name and a "47 days with Popular Network" badge
- Quick stats: posts published this month, engagement vs. last month, new reviews, ad spend used vs. budget, chatbot conversations (preview Tier 3)
- "Needs your attention" feed: 3 items pending approval, 1 negative review needing response, 1 spend reallocation recommendation
- "What the agent did this week" summary card

### 2. Content Calendar
- Month view showing scheduled posts across Facebook, Instagram, and Google Business Profile
- Color-coded by platform and by status (draft, pending approval, approved, published)
- Click a post to expand and see the draft, the AI's reasoning, and approve/edit/reject controls
- A "create new post" button (non-functional, just visible)

### 3. Approvals Queue
- List of items waiting for owner approval
- Each item shows: platform, draft content (with image placeholder), the AI's note about why it drafted this, and three buttons: Approve, Edit, Reject
- Show 3-5 items in different states

### 4. Performance
- Last 30 days vs. previous 30 days comparison
- Charts (use simple bar/line charts in CSS or inline SVG): reach, engagement, follower growth, top-performing posts
- Channel breakdown: organic vs. paid, by platform
- "What's working / what's not" insight cards generated by the agent

### 5. Reviews
- Recent reviews from Google and Facebook
- AI-drafted response visible for each, with Approve/Edit/Reject controls
- One negative review prominently flagged for fast response
- Aggregate rating trend over 6 months

### 6. Marketing Plan
- The Product Marketing Context summary (audience, value prop, switching forces, customer language, proof points)
- Editable sections (UI only, not functional)
- Channel allocation pie chart
- Q3 goals and current progress

### 7. AI Agent Chat
- Chat interface where the owner can talk to the agent
- Pre-populated conversation showing the owner asking "should I run a Memorial Day sale?" and the agent responding with a recommendation, draft post, and proposed boost budget
- Input box at bottom (non-functional but visible)

### 8. Settings (light)
- Tier indicator (Tier 2)
- Connected accounts (Facebook, Instagram, Google Business Profile — show as connected)
- Approval cadence preference
- "Talk to a human" button that opens a placeholder modal

## Visual quality bar

This is a partner demo. The dashboard needs to feel like a real, polished product — not an MVP wireframe.

- Clean, modern design — think Linear, Notion, or Stripe Dashboard quality
- Generous whitespace, thoughtful typography hierarchy
- A primary brand color (suggest a warm but professional tone — deep teal, navy, or a refined dark green works well for a publisher-affiliated brand)
- Consistent component styling (cards, buttons, badges)
- Responsive, but optimized for desktop demo viewing
- Subtle animations on interactions (Tailwind transition utilities)
- All icons via lucide-react
- Empty states should never appear — every section is fully populated
- No lorem ipsum anywhere — every word should be plausible content for Westbrook Auto & Tire

## Final deliverable

A single `dashboard.html` file at the project root that opens in any modern browser and renders the complete demo experience. Include a brief comment at the top of the file explaining how to open it and what it demonstrates.
